# MVP release check · November 17, 2026 (Pacific)

**NOT READY for a public Fremont pilot.** Local release evidence follows. The production launch gates are in [LAUNCH.md](../LAUNCH.md) and [DEPLOYMENT.md](../DEPLOYMENT.md).

- [x] **Release builds and type checks.** The production Next.js build and both Python wheels built. Engine, API, and ingestion passed Ruff and mypy. Web TypeScript passed. ESLint reported two warnings.
- [x] **Modeled optimization.** All 176 engine tests passed (98.94% coverage), including budget limits, deterministic selection, route impacts, and overlapping repairs. Web unit tests passed (135).
- [x] **Browser and automated accessibility.** All 48 Chromium tests passed against the production build. Coverage includes MapLibre markers, keyboard selection and list filtering, manual coordinate entry when the map fails, form retry, budget changes, and axe checks on eight pages at four widths. Browser reporting/planning flows use fixtures.
- [x] **Database, health, and reporting.** 208 API and 35 ingestion tests passed against disposable PostGIS 3.5.2. They cover migrations and rollback, liveness/readiness, report persistence, authorization, privacy, rate limits, rollback on failed writes, and street geometry. Compose reported healthy before host connections worked; wait for a successful PostGIS query. A fresh database without PostGIS hit the API's two-second migration statement timeout during extension creation; provision the extension first.
- [x] **Local release smoke test.** The production web build, API, and newly migrated database passed all ten HTTP checks in `scripts/verify-deployment.sh`, including both health endpoints and the proxied report summary. HTTPS/HSTS still requires a deployed endpoint.
- [ ] **Web formatting — web owner.** The format gate failed on `src/test/corridor-route.json`.
- [ ] **Route and repair correctness — API owner.** Five of seven focused snapshot and uncertainty regressions passed. A confirmed blocked node still returns an accessible route for colocated endpoints. Standalone planning accepts a stale snapshot ID (HTTP 200). Require both regressions to pass.
- [ ] **Fremont routing — ingestion and API owners.** [V] The last [staged audit](HANDOFF.md) checked 1,251 edges. Its saved results identify 130 off-network trip endpoints and 60 unverified access legs. The staged container was unavailable for a fresh audit. Routing and repair planning use synthetic networks. A displayed street layer does not validate pedestrian access.
- [ ] **Public operations and privacy — release owner.** Verify HTTPS/HSTS, proxy trust, least-privilege database credentials, persistent storage, monitoring, a tested restore, reviewer staffing, and report retention/takedown. Compose uses disposable tmpfs storage. The web config still lacks the required Content Security Policy. Independent auth review and manual VoiceOver/Safari and NVDA/Firefox sign-off remain open.
